2

Add the harness

This file is the referee. Every method gets its data, model, optimizer, evaluation, and logging from here, so no method gets an unfair advantage. It has four jobs:

  • Data: each hospital's training loader, the pooled training loader, and every hospital's own test set.
  • Training: train_sgd for pooled, local, and FedAvg; train_scaffold for SCAFFOLD, which adds c − c_i to each gradient.
  • SCAFFOLD plumbing: packing the control variate next to the model weights, and saving each hospital's c_i between rounds.
  • Logging: one CSV row per hospital per evaluation, with the method, seed, round, bytes uploaded, and git commit.
heart_fl/harness.py
"""Shared experiment harness for Fed-Heart-Disease.

Every method (pooled, local, FedAvg, SCAFFOLD) uses the SAME data splits,
model, optimizer, evaluation, and logging from this file, so the
comparisons are fair.
"""
import csv
import subprocess
import time
from collections import OrderedDict
from functools import lru_cache
from pathlib import Path

import numpy as np
import torch
from torch.utils.data import DataLoader
from flamby.datasets.fed_heart_disease import (
    BATCH_SIZE,
    NUM_CLIENTS,
    Baseline,
    BaselineLoss,
    FedHeartDisease,
    metric,
)

ROOT = Path(__file__).resolve().parents[1]          # the project folder
RESULTS_PATH = ROOT / "results" / "results.csv"
STATE_DIR = ROOT / "scaffold_state"                 # SCAFFOLD client memory (c_i)
CONTROL_PREFIX = "c."                               # marks control-variate tensors
FIELDS = ["timestamp", "commit", "method", "seed", "round", "client",
          "accuracy", "bytes_uploaded", "lr", "local_epochs"]


# ---------------------------------------------------------------- setup
def set_seed(seed: int):
    torch.manual_seed(seed)
    np.random.seed(seed)


def make_model():
    return Baseline()  # FLamby's reference model: identical for every method


# ---------------------------------------------------------------- data
def train_loader(center=None, pooled=False, seed=0):
    if pooled:  # all 4 hospitals' training data concatenated
        ds = FedHeartDisease(train=True, pooled=True)
    else:
        ds = FedHeartDisease(center=center, train=True, pooled=False)
    g = torch.Generator().manual_seed(seed)
    return DataLoader(ds, batch_size=BATCH_SIZE, shuffle=True, generator=g)


@lru_cache(maxsize=1)
def test_loaders():
    """Each hospital's own test set, plus the pooled test set."""
    loaders = {
        str(i): DataLoader(FedHeartDisease(center=i, train=False, pooled=False),
                           batch_size=BATCH_SIZE)
        for i in range(NUM_CLIENTS)
    }
    loaders["pooled"] = DataLoader(FedHeartDisease(train=False, pooled=True),
                                   batch_size=BATCH_SIZE)
    return loaders


# ---------------------------------------------------------------- training
def train_sgd(model, loader, lr, epochs):
    """Plain SGD. Used by pooled, local, and FedAvg clients."""
    opt = torch.optim.SGD(model.parameters(), lr=lr)
    loss_fn = BaselineLoss()
    model.train()
    for _ in range(epochs):
        for xb, yb in loader:
            opt.zero_grad()
            loss_fn(model(xb), yb).backward()
            opt.step()
    return model


def zeros_like_params(model):
    return OrderedDict((n, torch.zeros_like(p)) for n, p in model.named_parameters())


def train_scaffold(model, loader, lr, epochs, c, c_i, correction=True):
    """SCAFFOLD local training (Karimireddy et al., 2020, option II).

    Each step uses  g - c_i + c  instead of  g.
    Returns the trained model and the client's refreshed control variate.
    With correction=False the steps are identical to FedAvg (sanity check).
    """
    x = {n: p.detach().clone() for n, p in model.named_parameters()}
    opt = torch.optim.SGD(model.parameters(), lr=lr)
    loss_fn = BaselineLoss()
    model.train()
    steps = 0
    for _ in range(epochs):
        for xb, yb in loader:
            opt.zero_grad()
            loss_fn(model(xb), yb).backward()
            if correction:
                for n, p in model.named_parameters():
                    p.grad.add_(c[n] - c_i[n])        # g - c_i + c
            opt.step()
            steps += 1
    y = {n: p.detach().clone() for n, p in model.named_parameters()}
    c_i_new = OrderedDict(
        (n, c_i[n] - c[n] + (x[n] - y[n]) / (steps * lr)) for n in x
    )
    return model, c_i_new


# ---------------------------------------------------------------- SCAFFOLD packing
def pack_arrays(model_state, control):
    """Model weights + control variate in one dict (control keys get 'c.')."""
    out = OrderedDict(model_state)
    out.update((CONTROL_PREFIX + k, v) for k, v in control.items())
    return out


def split_arrays(state):
    """Inverse of pack_arrays. Returns (model_state, control)."""
    model_state = OrderedDict((k, v) for k, v in state.items()
                              if not k.startswith(CONTROL_PREFIX))
    control = OrderedDict((k[len(CONTROL_PREFIX):], v) for k, v in state.items()
                          if k.startswith(CONTROL_PREFIX))
    return model_state, control


def load_client_control(run_id, pid, model):
    path = STATE_DIR / f"run{run_id}_client{pid}.pt"
    return torch.load(path) if path.exists() else zeros_like_params(model)


def save_client_control(run_id, pid, c_i):
    STATE_DIR.mkdir(exist_ok=True)
    torch.save(c_i, STATE_DIR / f"run{run_id}_client{pid}.pt")


# ---------------------------------------------------------------- evaluation
@torch.no_grad()
def evaluate(model, loader):
    model.eval()
    ys, preds = [], []
    for xb, yb in loader:
        ys.append(yb)
        preds.append(model(xb))
    return float(metric(torch.cat(ys).numpy(), torch.cat(preds).numpy()))


def evaluate_all(model):
    """Accuracy on every hospital's test set and on the pooled test set."""
    return {name: evaluate(model, dl) for name, dl in test_loaders().items()}


def array_bytes(state):
    return sum(t.numel() * t.element_size() for t in state.values())


# ---------------------------------------------------------------- logging
def _git_commit():
    try:
        return subprocess.check_output(
            ["git", "rev-parse", "--short", "HEAD"], cwd=ROOT,
            stderr=subprocess.DEVNULL).decode().strip()
    except Exception:
        return "nogit"


def log(method, seed, accs, round_=-1, bytes_uploaded=0, lr=None, local_epochs=None):
    """Append one row per client to results/results.csv."""
    RESULTS_PATH.parent.mkdir(exist_ok=True)
    new_file = not RESULTS_PATH.exists()
    with open(RESULTS_PATH, "a", newline="") as f:
        w = csv.DictWriter(f, fieldnames=FIELDS)
        if new_file:
            w.writeheader()
        for client, acc in accs.items():
            w.writerow({
                "timestamp": time.strftime("%Y-%m-%d %H:%M:%S"),
                "commit": _git_commit(), "method": method, "seed": seed,
                "round": round_, "client": client, "accuracy": round(acc, 4),
                "bytes_uploaded": bytes_uploaded, "lr": lr,
                "local_epochs": local_epochs,
            })
3

Run pooled and local-only baselines

Pooled trains one model on all four hospitals' training data concatenated. That's the ceiling: what you'd get if hospitals could share everything. Local-only trains a separate model per hospital on its own data. That's the floor. Federated methods should land between them, hopefully near the ceiling.

baselines.py
"""Pooled (ceiling) and local-only (floor) baselines. No Flower needed.

    python baselines.py --seeds 0 1 2 3 4 --lr 0.01 --epochs 50
"""
import argparse

from heart_fl.harness import (NUM_CLIENTS, evaluate, evaluate_all, log, make_model,
                              set_seed, test_loaders, train_loader, train_sgd)

p = argparse.ArgumentParser()
p.add_argument("--seeds", type=int, nargs="+", default=[0, 1, 2, 3, 4])
p.add_argument("--lr", type=float, default=0.01)
p.add_argument("--epochs", type=int, default=50)
p.add_argument("--tag", default="", help="suffix for method names, e.g. _lr0.1 while tuning")
args = p.parse_args()

for seed in args.seeds:
    # Pooled: one model trained on every hospital's data, tested on each hospital
    set_seed(seed)
    model = train_sgd(make_model(), train_loader(pooled=True, seed=seed), args.lr, args.epochs)
    accs = evaluate_all(model)
    log("pooled" + args.tag, seed, accs, lr=args.lr, local_epochs=args.epochs)
    print(f"seed {seed} pooled: " + ", ".join(f"{k}={v:.3f}" for k, v in accs.items()))

    # Local-only: each hospital trains alone, tested on its own test set
    for i in range(NUM_CLIENTS):
        set_seed(seed)
        model = train_sgd(make_model(), train_loader(center=i, seed=seed), args.lr, args.epochs)
        acc = evaluate(model, test_loaders()[str(i)])
        log("local" + args.tag, seed, {str(i): acc}, lr=args.lr, local_epochs=args.epochs)
        print(f"seed {seed} local client {i}: {acc:.3f}")

Pick a learning rate first

Try three values on one seed. The --tag keeps them apart in the results file.

Terminal
python baselines.py --seeds 0 --lr 0.001 --tag _lr0.001
python baselines.py --seeds 0 --lr 0.01  --tag _lr0.01
python baselines.py --seeds 0 --lr 0.1   --tag _lr0.1
python summarize.py

Pick the rate with the best pooled mean and use it for every method. Write the choice in your notebook. run_all.sh archives these tuning rows automatically, so they won't mix into the final table.

If every accuracy sits around the same value no matter what, the model is probably predicting one class for everything. Try a larger learning rate or more epochs.

Configure pyproject.toml

Keep your existing [project] and [tool.flwr.app.components] sections. Replace the [tool.flwr.app.config] section and set the number of simulated nodes to 4.

pyproject.toml (the parts to change)
[tool.flwr.app.config]
num-server-rounds = 50       # 50 rounds x 1 local epoch = 50 pooled epochs
local-epochs = 1
lr = 0.01                    # the value you picked in step 3
seed = 0
method = "fedavg"            # "fedavg" or "scaffold"
scaffold-correction = true   # false only for the sanity check in step 8

[tool.flwr.federations.local-simulation]
options.num-supernodes = 4   # one simulated node per hospital

Any key here can be overridden per run without editing the file, for example flwr run . --run-config "method='scaffold' seed=3". Strings need single quotes inside the double quotes.

If your pyproject.toml has no [tool.flwr.federations] section, your Flower version keeps simulation settings in a separate config file. Set 4 nodes there instead.

5

Replace client_app.py

Each simulated node is one hospital (partition-id 0–3). Every round it receives the global model, trains on its own data, and sends weights back. For SCAFFOLD it also receives the server's c, loads its own c_i from disk, and sends back its refreshed c_i packed next to the weights.

heart_fl/client_app.py
"""Flower ClientApp for Fed-Heart-Disease. Runs FedAvg or SCAFFOLD (run config 'method')."""
from collections import OrderedDict

from flwr.app import ArrayRecord, Context, Message, MetricRecord, RecordDict
from flwr.clientapp import ClientApp

from heart_fl.harness import (evaluate, load_client_control, make_model, pack_arrays,
                              save_client_control, set_seed, split_arrays,
                              test_loaders, train_loader, train_scaffold, train_sgd)

app = ClientApp()


@app.train()
def train(msg: Message, context: Context):
    cfg = context.run_config
    method = cfg["method"]
    lr, epochs, seed = float(cfg["lr"]), int(cfg["local-epochs"]), int(cfg["seed"])
    pid = int(context.node_config["partition-id"])          # hospital 0..3
    server_round = int(msg.content["config"].get("server-round", 0))

    shuffle_seed = seed * 1000 + server_round * 10 + pid
    set_seed(shuffle_seed)
    loader = train_loader(center=pid, seed=shuffle_seed)

    # Global weights (and, for SCAFFOLD, the server control variate c)
    model_state, c = split_arrays(msg.content["arrays"].to_torch_state_dict())
    model = make_model()
    model.load_state_dict(model_state)

    if method == "fedavg":
        train_sgd(model, loader, lr, epochs)
        out = OrderedDict(model.state_dict())
    elif method == "scaffold":
        c_i = load_client_control(context.run_id, pid, model)   # this hospital's memory
        _, c_i_new = train_scaffold(model, loader, lr, epochs, c, c_i,
                                    correction=bool(cfg["scaffold-correction"]))
        save_client_control(context.run_id, pid, c_i_new)
        out = pack_arrays(model.state_dict(), c_i_new)          # send y and c_i
    else:
        raise ValueError(f"unknown method {method!r}")

    content = RecordDict({
        "arrays": ArrayRecord(out),
        "metrics": MetricRecord({"num-examples": len(loader.dataset)}),
    })
    return Message(content=content, reply_to=msg)


@app.evaluate()
def client_evaluate(msg: Message, context: Context):
    """Not used (server evaluates centrally), kept so the app stays valid."""
    pid = int(context.node_config["partition-id"])
    model_state, _ = split_arrays(msg.content["arrays"].to_torch_state_dict())
    model = make_model()
    model.load_state_dict(model_state)
    loader = test_loaders()[str(pid)]
    metrics = MetricRecord({"accuracy": evaluate(model, loader),
                            "num-examples": len(loader.dataset)})
    return Message(content=RecordDict({"metrics": metrics}), reply_to=msg)

Replace server_app.py

The server builds the initial model from the same seed as the baselines, runs the rounds with Flower's FedAvg strategy, and scores the global model centrally on every hospital's test set after each round. That central evaluation is what writes the CSV rows.

heart_fl/server_app.py
"""Flower ServerApp for Fed-Heart-Disease. FedAvg or SCAFFOLD, evaluated centrally."""
from collections import OrderedDict

from flwr.app import ArrayRecord, Context, MetricRecord
from flwr.serverapp import Grid, ServerApp
from flwr.serverapp.strategy import FedAvg

from heart_fl.harness import (NUM_CLIENTS, array_bytes, evaluate_all, log, make_model,
                              pack_arrays, set_seed, split_arrays, zeros_like_params)

app = ServerApp()


@app.main()
def main(grid: Grid, context: Context) -> None:
    cfg = context.run_config
    method = cfg["method"]
    seed, lr = int(cfg["seed"]), float(cfg["lr"])
    epochs, rounds = int(cfg["local-epochs"]), int(cfg["num-server-rounds"])

    set_seed(seed)                       # same initial model as the baselines
    model = make_model()
    init = OrderedDict(model.state_dict())
    if method == "scaffold":             # add server control variate c = 0
        init = pack_arrays(init, zeros_like_params(model))
    upload_per_client = array_bytes(init)    # SCAFFOLD is ~2x FedAvg

    name = method
    if method == "scaffold" and not cfg["scaffold-correction"]:
        name = "scaffold-check"          # should match fedavg exactly

    def global_evaluate(server_round: int, arrays: ArrayRecord) -> MetricRecord:
        model_state, _ = split_arrays(arrays.to_torch_state_dict())
        m = make_model()
        m.load_state_dict(model_state)
        accs = evaluate_all(m)
        log(name, seed, accs, round_=server_round,
            bytes_uploaded=server_round * NUM_CLIENTS * upload_per_client,
            lr=lr, local_epochs=epochs)
        return MetricRecord({f"acc_{k}": v for k, v in accs.items()})

    # All 4 hospitals train every round; no client-side evaluation.
    # FedAvg averages everything in the returned arrays, so for SCAFFOLD it
    # averages the models (new x) AND the client c_i's (new c).
    strategy = FedAvg(fraction_train=1.0, fraction_evaluate=0.0)
    strategy.start(grid=grid, initial_arrays=ArrayRecord(init),
                   num_rounds=rounds, evaluate_fn=global_evaluate)

8

Sanity-check SCAFFOLD

With the correction switched off, SCAFFOLD's local steps are exactly FedAvg's. So with the same seed, the accuracies must match FedAvg to the last digit. Only bytes_uploaded differs (twice as large). If they don't match, there's a bug. Find it now, not after the full runs.

Terminal
flwr run . --run-config "method='fedavg' num-server-rounds=5"
flwr run . --run-config "method='scaffold' scaffold-correction=false num-server-rounds=5"
flwr run . --run-config "method='scaffold' num-server-rounds=5"

Compare the round-5 rows for fedavg and scaffold-check: identical. The real scaffold run should differ a little. Screenshot the matching rows; it's good evidence for your notebook.

10

Read the results

summarize.py writes three files to results/:

  • summary.md: per-hospital accuracy (mean ± std over seeds) for every method, then the mean and worst hospital for each method, then the fraction of the local-to-pooled gap each federated method closes.
  • accuracy_vs_round.png: FedAvg and SCAFFOLD learning curves, with the final pooled and local accuracy as reference lines.
  • accuracy_vs_bytes.png: the same curves against bytes uploaded, where SCAFFOLD pays for its 2× communication.
summarize.py
"""Turn results/results.csv into a table (results/summary.md) and two plots.

    python summarize.py
"""
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("results/results.csv", dtype={"client": str})
hospitals = df[df["client"] != "pooled"]

# ---------- final-round table
final = hospitals[hospitals["round"] ==
                  hospitals.groupby(["method", "seed"])["round"].transform("max")]
mean = final.groupby(["client", "method"])["accuracy"].mean().unstack("method")
std = final.groupby(["client", "method"])["accuracy"].std().unstack("method").fillna(0)
order = ["local", "pooled", "fedavg", "scaffold", "scaffold-check"]
methods = [m for m in order if m in mean.columns] + \
          [m for m in mean.columns if m not in order]

lines = ["## Per-hospital test accuracy (mean ± std over seeds)", "",
         "| hospital | " + " | ".join(methods) + " |",
         "|---" * (len(methods) + 1) + "|"]
for c in mean.index:
    lines.append(f"| {c} | " + " | ".join(
        f"{mean.loc[c, m]:.3f} ± {std.loc[c, m]:.3f}" for m in methods) + " |")

lines += ["", "## Summary", "", "| method | mean over hospitals | worst hospital |",
          "|---|---|---|"]
for m in methods:
    lines.append(f"| {m} | {mean[m].mean():.3f} | {mean[m].min():.3f} |")

if {"local", "pooled"} <= set(methods):
    gap = mean["pooled"] - mean["local"]
    lines += ["", "## Fraction of gap closed: (fed − local) / (pooled − local)", ""]
    for m in methods:
        if m in ("local", "pooled"):
            continue
        closed = ((mean[m] - mean["local"]) / gap.where(gap.abs() > 1e-9)).mean()
        lines.append(f"- {m}: {closed:.2f}")

out = "\n".join(lines)
print(out)
with open("results/summary.md", "w") as f:
    f.write(out + "\n")

# ---------- curves: mean accuracy over hospitals, averaged over seeds
fed = hospitals[hospitals["round"] >= 0]
curves = fed.groupby(["method", "seed", "round", "bytes_uploaded"])["accuracy"].mean() \
            .groupby(["method", "round", "bytes_uploaded"]).mean().reset_index()

for x, fname, label in [("round", "accuracy_vs_round.png", "server round"),
                        ("bytes_uploaded", "accuracy_vs_bytes.png", "total bytes uploaded")]:
    fig, ax = plt.subplots(figsize=(6, 4))
    for m, g in curves.groupby("method"):
        ax.plot(g[x], g["accuracy"], label=m)
    for m, style in [("pooled", "--"), ("local", ":")]:
        if m in mean.columns:
            ax.axhline(mean[m].mean(), linestyle=style, color="grey", label=f"{m} (final)")
    ax.set_xlabel(label)
    ax.set_ylabel("mean test accuracy over hospitals")
    ax.set_title("Fed-Heart-Disease")
    ax.legend()
    fig.tight_layout()
    fig.savefig(f"results/{fname}", dpi=150)
    print(f"saved results/{fname}")

What to expect

FedAvg should land close to pooled; Fed-Heart-Disease is one of the two FLamby datasets where federated reaches pooled. Local-only should be weaker, especially at the small hospitals. SCAFFOLD will probably be within noise of FedAvg, because four hospitals with one local epoch leaves little room for client drift. That's a valid result: it means this dataset doesn't stress drift, not that SCAFFOLD failed.

Red flag: FedAvg far below pooled. On this dataset that almost always means a bug (wrong test sets, mismatched learning rate, or aggregation that isn't using all four hospitals).

How SCAFFOLD fits in

In SCAFFOLD the server keeps two things: the model x and a control variate c, the average drift direction. Each hospital keeps its own c_i. Every local step uses g − c_i + c instead of the plain gradient g: it removes the hospital's own drift and adds back the shared one, so hospitals stop pulling the model toward what suits only them.

After local training, a hospital refreshes its estimate with c_i_new = c_i − c + (x − y) / (K · lr), where y is its trained model and K the number of local steps.

The server update is normally x ← x + mean(Δy) and c ← c + mean(Δc_i). When every hospital participates in every round, as here, those reduce to "average the models" and "average the c_i's". That's what FedAvg already does to whatever arrays it receives. So each hospital sends its weights and its c_i in one bundle (control tensors are prefixed c.), and FedAvg produces the new x and the new c in one step. No custom strategy is needed.

Two choices to record in your notebook: averaging is weighted by sample count (the same as your FedAvg arm), and this shortcut only holds with full participation. If you ever sample a subset of hospitals per round, you'd need a proper custom strategy.

Terms

Harness
The shared code that runs every method the same way, so comparisons are fair.
Pooled
One model trained on all hospitals' data combined. The accuracy ceiling.
Local-only
Each hospital trains alone. The accuracy floor.
Client drift
With different data, each hospital's local training pulls the model toward what suits it, so the average lands somewhere worse.
Control variate
SCAFFOLD's running estimate of a drift direction: c_i per hospital, c on the server.
Bytes uploaded
Total data hospitals send to the server. The real communication cost in cross-silo FL, which is why the second plot uses it.
Fraction of gap closed
(federated − local) / (pooled − local). 1 means federated matches pooled; 0 means it's no better than training alone.
